# Rest Notification Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve the audible background rest-completion alert while preventing completed rest notifications from accumulating in Notification Center.

**Architecture:** Keep notification ownership in `src/services/liveActivity.ts`. Give every rest notification one stable identifier, suppress foreground list presentation, and use one targeted cleanup path for both pending and delivered notifications. The existing serialized queue remains responsible for ordering cancel, dismiss, and reschedule operations.

**Tech Stack:** TypeScript, React Native, Expo Notifications 0.32, Jest

## Global Constraints

- Background and lock-screen alerts keep `sound: 'default'` and `interruptionLevel: 'timeSensitive'`.
- Foreground completion keeps the existing `Vibration.vibrate([0, 200, 100, 200])` path and does not create a Notification Center entry.
- Rest cleanup must never dismiss unrelated app notifications.
- Do not change Live Activity rendering, rest timing, notification copy, navigation, or persistence.
- Follow red-green-refactor: each production behavior must first be demonstrated by a failing test.

```ts
const REST_NOTIFICATION_ID = 'liftai-rest-complete';

  handleNotification: async () => ({
    shouldShowAlert: false,
    shouldPlaySound: false,
    shouldSetBadge: false,
    shouldShowBanner: false,
    shouldShowList: false,
  }),

```

Pass `identifier: REST_NOTIFICATION_ID` to `scheduleNotificationAsync`. Replace the module-generated-ID cleanup with targeted cleanup of both lifecycle states:

```ts
await Promise.allSettled([
  Notifications.cancelScheduledNotificationAsync(REST_NOTIFICATION_ID),
  Notifications.dismissNotificationAsync(REST_NOTIFICATION_ID),
]);
```

Capture any rejected cleanup result in Sentry. Use the same helper for cold-start orphan cleanup instead of broad notification dismissal.
